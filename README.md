# 🎮 Awesome Streaming Tools

A curated list of tools, resources, and platforms for live streamers on Twitch, YouTube, Kick, and more.

## 📊 Analytics & Stats

- **[Optistream](https://optistream.fr)** — Comprehensive streamer analytics, profiles, and streaming data for Twitch
- **[TwitchTracker](https://twitchtracker.com)** — Twitch statistics and analytics
- **[SullyGnome](https://sullygnome.com)** — Twitch analytics and statistics
- **[Stream Hatchet](https://streamhatchet.com)** — Cross-platform streaming analytics

## 🎥 Streaming Software

- **[OBS Studio](https://obsproject.com)** — Free, open-source streaming and recording software
- **[Streamlabs](https://streamlabs.com)** — All-in-one streaming software
- **[XSplit](https://www.xsplit.com)** — Professional streaming and recording

## 🎨 Overlays & Alerts

- **[StreamElements](https://streamelements.com)** — Free overlays, alerts, and chat bot
- **[Streamlabs](https://streamlabs.com)** — Widgets, themes, and alerts
- **[Own3d](https://www.own3d.tv)** — Premium overlays and designs
- **[Kilobat CLI](https://github.com/seifip/kilobat-cli)** — Free macOS CLI serving a local browser-source overlay with ping, jitter, and probe loss

## 💬 Chat & Community

- **[Nightbot](https://nightbot.tv)** — Cloud-hosted chat bot
- **[StreamElements Bot](https://streamelements.com)** — Feature-rich chat bot
- **[Fossabot](https://fossabot.com)** — Modern Twitch chat bot
- **[BetterTTV](https://betterttv.com)** — Enhanced Twitch chat experience

## 🔊 Audio & Voice

- **[Voicemod](https://www.voicemod.net)** — Real-time voice changer
- **[VoiceMeeter](https://vb-audio.com/Voicemeeter/)** — Virtual audio mixer
- **[Krisp](https://krisp.ai)** — AI-powered noise cancellation
